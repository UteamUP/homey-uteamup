Bring your UteamUP maintenance work into the home or building you already automate with Homey. See open, in-progress, on-hold and overdue work orders, stock alerts and IoT alerts as live values, and let Flows react when work becomes overdue or an alert starts.

Flows can also report a problem when a leak or smoke sensor goes off, create and complete work orders, change their status, set an asset's state, run preventive maintenance and record meter readings. You connect with a UteamUP API key from a company on the Premium or Enterprise plan; the key's role decides what Homey may see and do.
